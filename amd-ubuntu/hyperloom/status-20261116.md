- **Expert parallel alone:** cannot run. Kimi-K3's MoE uses the a16w4 SiTUv2 kernel, and aiter
  refuses expert parallel for it (`fused_moe.py`: "a16w4 (bf16 A x MXFP4 W) SiTUv2 is not
  supported: expert-parallel masking"). This was the Nov 12 "SHUTDOWN signal from DP rank 0" error.
- **a8w4 (`--moe-backend mega`):** needs expert parallel, so it was run with
  `--enable-expert-parallel`. It fails at startup, twice: "mega hardcodes SwiGLU; got
  activation=ActivationType.Situv2" (`atom/model_ops/fused_moe/flydsl_mega_experts.py` line 373).
  Kimi-K3 uses the SiTUv2 activation, which the mega kernel does not support.
- So neither candidate can run on Kimi-K3 with this ATOM image. A fix needs a code change in
  ATOM/aiter (SiTUv2 in the mega kernel, or expert-parallel masking in the a16w4 kernel), or a newer
  image that has it.
- MoE tile tuning: still deferred (expected +0.3%, inside the noise).
